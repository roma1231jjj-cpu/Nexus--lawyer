# Nexus-Юрист 1.0.6

Правовой помощник Nexus × АутSquad. Исправления по аудиту хранения и вложений.

## Что исправлено

- Повреждённый `cases.json`/настройки больше не затираются: файл уводится в `.corrupt-*`, а если копию сохранить не удалось — запись блокируется.
- Повреждённый файл отличается от отсутствующего: приложение не считает пустую базу нормальной.
- Одинаковые имена вложений не перезаписывают друг друга; откат неудачного прикрепления не удаляет старое вложение.
- ID дела очищается от `..` и слэшей; открыть/удалить можно только файл внутри папки этого дела.
- Удаление файла/дела сначала убирает файл и только потом запись; при ошибке доступа запись остаётся и ошибка показывается.
- Вложения открываются по проверенному пути; ошибка открытия выводится в интерфейсе.
