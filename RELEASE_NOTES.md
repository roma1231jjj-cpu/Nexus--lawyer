# Nexus-Юрист 1.0.0

Первый стабильный выпуск правового помощника экосистемы **Nexus × АутSquad**.

## Что внутри

- Консультации с ИИ по нормам: локальная база 228 норм, 16 стран; ответы со ссылками на статьи.
- Справочный режим без модели: подбор норм по запросу.
- Шесть шаблонов документов: претензия, судебный приказ, трудовое заявление, потребительская претензия, договор аренды, доверенность. Выгрузка в `.doc`, `.md`, `.txt`.
- Дела: карточки, заметки, вложенные файлы — всё локально.
- Три темы: Midnight, Ivory, Aurum.
- Подключение любой OpenAI-совместимой модели: Ollama, llama.cpp, Ada 4B, Nexus-Harness, облако.
- Автообновление: GitHub Releases или свой generic-сервер, каналы stable/beta.

## Файлы

| Файл | Что это |
|---|---|
| `nexus-lawyer-setup-1.0.0.exe` | установщик NSIS, ставится без прав администратора, поддерживает автообновление |
| `nexus-lawyer-setup-1.0.0.exe.blockmap` | блок-карта для дифференциальных обновлений |
| `latest.yml` | метаданные обновления |
| `nexus-lawyer-1.0.0-portable.exe` | портативный один файл |
| `nexus-lawyer-1.0.0-portable.zip` | портативная папка в архиве |

Контрольные суммы — `versions/v1.0.0/manifest.json` в репозитории.

## Требования

Windows 10/11 x64. Модель ИИ не входит в поставку: укажите адрес сервера в «Настройках» (по умолчанию `http://127.0.0.1:11434/v1`).

Тексты норм — справочные выдержки. Проверяйте актуальную редакцию на официальных порталах: приложение помогает готовить требования, но не заменяет адвоката.
